Le **BME280** mesure la **température**, l'**humidité de l'air** et la **pression atmosphérique**. Il convient aux stations météo, serres et projets de suivi environnemental avec **Natulib OS**. Il ne mesure pas l'humidité du sol.

## 🛒 Ce qu'il vous faut

| Composant | Lien d'achat | Note / Rôle |
| --- | --- | --- |
| **Module BME280 I²C** | [AliExpress](https://fr.aliexpress.com/w/wholesale-bme280.html) | Capteur environnemental BME280. |
| **fils Dupont** | — | Alimentation et bus I²C. |

## 🚀 Pour commencer

1. Souder la barrette de six broches si nécessaire.
2. **Couper l'alimentation** de l'ESP32-C6.
3. Raccorder le BME280 : **VCC → 3V3**, **GND → GND**, **SDA → GPIO4**,**SCL → GPIO5** et **CSB → 3V3**
4. Démarrer Natulib OS puis ouvrir **Hardware**.
5. Ajouter le **Capteur BME280 (Air)**, vérifier les broches **SDA/SCL**, puis **enregistrer**.
6. **Redémarrer l'ESP32** pour prendre en compte le nouveau module.
7. Ouvrir **Accueil** et vérifier l'apparition des trois mesures.

## 🧪 Validation rapide

| Vérification | Résultat attendu |
| --- | --- |
| Capteur connecté | `online = 1`. |
| Température | Valeur plausible en **°C**. |
| Humidité de l'air | Valeur plausible en **%**. |
| Pression atmosphérique | Valeur plausible en **hPa**. |
| Redémarrage de l'ESP32-C6 | Les mesures réapparaissent. |

## 🧩 Dans Natulib

Dans **Hardware**, le type interne est **`bme280`**. Dans **Accueil** et **Synapses**, les mesures sont disponibles avec l'identifiant choisi pour le capteur :

| Mesure | Clé (exemple avec `meteo_box`) |
| --- | --- |
| Température | `meteo_box.t` |
| Humidité de l'air | `meteo_box.h_air` |
| Pression | `meteo_box.p` |
| Connexion | `meteo_box.online` (1 ou 0) |

Le driver recherche automatiquement le BME280 aux adresses I²C **`0x76`** et **`0x77`** et tente de se reconnecter en cas de perte de communication.

Une **correction de température** peut être réglée dans Hardware après comparaison avec un thermomètre de référence.

## ⚙️ Configuration de référence

Exemple simplifié du profil BME280. **Adapter SDA et SCL au câblage réel** :

```json
{
  "id": "meteo_box",
  "type": "bme280",
  "pins": {
    "sda": 4,
    "scl": 5
  },
  "interval_ms": 300000,
  "offset": { "t": 0.0 },
  "active": true
}
```

`interval_ms: 300000` correspond à une lecture demandée toutes les **5 minutes**. `offset.t` permet d'ajuster la température en °C ; **0** signifie aucune correction.

## 🛠️ Problèmes courants

| Problème | Vérification |
| --- | --- |
| **Aucune mesure après l'ajout** | Enregistrer le module puis **redémarrer l'ESP32-C6**. |
| **Capteur non détecté** | Vérifier VCC, GND, SDA/SCL, le brochage réel et la **Console**. |
| **Mesures incohérentes** | Vérifier qu'il s'agit bien d'un **BME280**, et non d'un autre capteur similaire. |
| **Température trop élevée** | Éloigner le capteur de la chaleur de l'ESP32 et comparer avec une référence. |
| **Déconnexions** | Vérifier les fils et le bus I²C ; le driver tente une reconnexion. |
