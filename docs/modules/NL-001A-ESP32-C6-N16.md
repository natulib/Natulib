**À retenir :** cette carte est le **cœur de Natulib**. Aucun capteur, écran ou shield n'est nécessaire pour sa première mise en service.

## 🔌 Branchement minimal

**Il faut :** une carte **ESP32-C6 N16**, un ordinateur et un **câble USB-C qui transporte les données**.

1. Laisser les **GPIO sans connexion** pour le premier démarrage.
2. Brancher le câble sur le port USB-C **UART / CH343** de la carte illustrée (port conseillé pour commencer le flash).
3. Suivre le [guide d'installation de Natulib OS](../Installation.md).

> **2 min** correspondent au raccordement de la carte ; prévoir du temps supplémentaire pour le premier flash et la configuration réseau. Le [shield NL-002A](./NL-002A-ESP32-Expansion-Shield.md) est **facultatif** à cette étape. Pour un montage sur shield sans soudure, choisir une carte dont les broches sont déjà soudées.

## 🚀 Première mise en service

Après avoir flashé **Natulib OS**, effectuer seulement ces **trois vérifications** :

- [ ] **Flash terminé sans erreur** dans l'outil d'installation.
- [ ] **Interface Web Natulib accessible**, selon le mode réseau indiqué dans le guide d'installation.
- [ ] **Redémarrage réussi** : appuyer sur RESET (ou débrancher/rebrancher l'USB), puis vérifier que l'interface redevient accessible.

**Si ces trois points sont OK, la carte est prête.** Aucun autre test matériel n'est obligatoire à ce stade. Les capteurs, écrans et actionneurs seront testés lors de l'ajout de leurs propres fiches.

> ⚠️ **USB-C = alimentation 5 V via la carte ; GPIO = logique 3,3 V.** Ne jamais appliquer directement 5 V sur une GPIO. Couper l'alimentation avant de brancher un module.

## 🧭 Repères des connexions et des GPIO

Le **plan des GPIO est disponible en deuxième image de la galerie** en haut de cette fiche. Il correspond à la carte illustrée : toujours comparer avec la sérigraphie de sa propre variante avant de câbler.

| Repère | À quoi sert-il ? |
|---|---|
| **USB-C UART / CH343** | Alimentation, flash et console série par convertisseur USB-UART. |
| **USB-C USB** | Port USB natif de l'ESP32-C6, utilisable aussi pour le flash selon l'outil et la configuration. |
| **3V3 / GND** | Alimentation 3,3 V des petits périphériques et masse commune. |
| **GPIO** | Entrées/sorties pour les modules. Le GPIO est choisi **dans Hardware et dans chaque projet**, pas globalement pour tous les montages. |
| **BOOT / GPIO9** | Entrée en mode programmation si nécessaire, avec RESET. |
| **RESET / RST** | Redémarrage de la carte. |

**À connaître avant de brancher un périphérique :**

- **GPIO4, 5, 8, 9 et 15** ont un rôle lors du démarrage (*strapping*) : ne pas imposer un niveau électrique inadapté au démarrage.
- **GPIO12 et GPIO13** servent à l'USB natif ; **GPIO16 et GPIO17** correspondent à l'UART0 sur cette famille de cartes. Vérifier leur usage avant de les réaffecter.
- **GPIO11** peut, par exemple, recevoir le signal `OUT` du **TTP223** dans ton montage actuel ; ce n'est **pas un branchement universel** pour Natulib.

## 🧩 Utilisation dans Natulib

Le NL-001A **exécute Natulib OS** : il ne s'ajoute donc **pas comme un capteur dans Hardware**. On déclare dans Hardware les périphériques branchés sur ses GPIO.

**Côté puce**, l'ESP32-C6 prend en charge le Wi-Fi 2,4 GHz, le Bluetooth LE et les technologies IEEE 802.15.4 (Zigbee/Thread). Leur prise en charge **effective dans Natulib OS** dépend des fonctions du firmware installées et testées.

## 🛠️ Si le démarrage ne fonctionne pas

| Symptôme | Premier contrôle |
|---|---|
| **Aucun port série détecté** | Utiliser un câble USB-C **données** et essayer le port **UART / CH343**. Vérifier si un pilote USB-série est nécessaire sur l'ordinateur. |
| **Flash impossible** | Vérifier la sélection du port et de la carte. Si l'outil le demande, maintenir **BOOT**, appuyer brièvement sur **RESET**, puis relâcher BOOT. |
| **Flash OK, interface inaccessible** | Vérifier la procédure réseau du [guide d'installation](../Installation.md), puis redémarrer la carte. |
| **La carte cesse de démarrer après câblage** | Débrancher les périphériques et réessayer avec la carte seule. Contrôler en priorité les broches de démarrage et les tensions. |

## 👀 En bref

Le **NL-001A** est la carte principale d'une station Natulib, basée sur un **ESP32-C6 avec 16 Mo de mémoire Flash**.

Elle exécute **Natulib OS**, pilote les modules connectés et assure les communications sans fil.

Elle permet notamment de :

- 🌱 exécuter Natulib OS ;
- 🌡️ lire les capteurs ;
- 📺 piloter les écrans ;
- ⚙️ commander les actionneurs ;
- 🌐 héberger l'interface Web locale ;
- 📡 communiquer en Wi-Fi 6, Bluetooth LE, Zigbee et Thread.

**Montage :** sans outil avec le [NL-002A](./NL-002A-ESP32-Expansion-Shield.md) · **Alimentation :** USB-C · **Logique :** 3,3 V.

> ⚠️ Choisissez la version **ESP32-C6 N16 avec broches déjà soudées**. La version sans broches nécessite une soudure avant de pouvoir être utilisée avec les modules Natulib.

## 🛠️ Installation en 2 minutes

1. Vérifiez que les broches de l'ESP32-C6 sont déjà soudées.
2. Insérez la carte dans le **[NL-002A](./NL-002A-ESP32-Expansion-Shield.md)**.
3. Vérifiez l'orientation du connecteur USB-C.
4. Connectez les modules Natulib au shield.
5. Branchez le câble USB-C.

> 🔧 Aucun fer à souder n'est nécessaire avec une carte équipée de ses broches et le NL-002A.

---

## 🚀 Démarrage

Pour installer **Natulib OS**, suivez le [guide d'installation](../Installation.md).

### ⚡ Alimentation

- Utilisez une alimentation USB-C stable.
- Une alimentation **5 V / 1 A minimum** est recommandée.
- Coupez l'alimentation avant toute modification du câblage.

> ⚠️ Les GPIO de l'ESP32-C6 fonctionnent en **3,3 V**. N'appliquez jamais une tension supérieure directement sur une GPIO.

---

## 🧩 Problèmes courants

**La carte n'apparaît pas comme port série**
→ Le câble USB-C doit transporter les données, pas seulement l'alimentation.

**Le démarrage échoue après ajout d'un module**
→ Vérifiez qu'aucun module n'impose un niveau sur GPIO8, GPIO9 ou GPIO15 pendant la mise sous tension.
