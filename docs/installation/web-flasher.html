Installer Natulib OS

Branchez votre carte en USB-C, choisissez la version qui correspond à votre carte, puis cliquez sur Installer.

Prérequis : un navigateur Chrome ou Edge sur ordinateur (Firefox, Safari et les mobiles ne prennent pas en charge Web Serial) et un câble USB-C qui transporte les données.

Repérez la référence gravée sur le blindage métallique du module ESP32-C6 : N16 pour 16 Mo, N8 pour 8 Mo. Ne flashez pas une version prévue pour plus de mémoire que celle de votre carte : elle risquerait de ne pas démarrer. La version 16 Mo est présélectionnée : vérifiez la référence de votre carte avant d’installer. En cas de doute, choisissez la version 8 Mo : elle fonctionne sur les deux cartes.

Ce navigateur ne prend pas en charge Web Serial. Ouvrez cette page avec Chrome ou Edge sur ordinateur.

Si l’installation ne démarre pas

  • Aucun port n’apparaît : essayez un autre câble USB-C, certains ne transportent que l’alimentation. Vérifiez aussi que le pilote CP2102 ou CH340 (selon la puce USB-série de votre carte) est installé.
  • L’écriture échoue en cours de route : maintenez le bouton BOOT de la carte enfoncé quelques secondes après avoir cliqué sur Installer, puis relâchez.
  • Vous changez de version (par exemple 8 Mo vers 16 Mo, ou Standard vers Zigbee) : cochez l’option d’effacement de l’appareil quand elle est proposée, car la répartition de la mémoire change.

L’installeur utilise ESP Web Tools : il détecte le port série et écrit le firmware directement depuis le navigateur.

Pour compiler depuis les sources, consultez l’installation PlatformIO.
