# 🤝 Contribuer

Natulib est un projet Open Source construit collectivement.

Que vous développiez un module électronique, un projet complet, une recette biologique, un avatar ou une amélioration logicielle, toute contribution est la bienvenue.

---

## 📚 Guides de contribution

* **[Créer un module](./contribute/module.md)** — Ajouter une nouvelle brique matérielle (NL-XXX).
* **[Créer un projet](./contribute/projet.md)** — Documenter une station complète et reproductible.
* **[Créer une recette](./contribute/recette.md)** — Décrire les besoins biologiques d'une espèce ou d'un écosystème.
* **[Créer un avatar](./contribute/avatar.md)** — Partager un nouveau visage ou une animation pour Natulib.
* **[Développer Natulib OS](./contribute/natulib-os.md)** — Étendre le firmware, ajouter un driver ou améliorer le système.
* **[Améliorer la documentation](./contribute/documentation.md)** — Corriger ou enrichir le Wiki.

---

Toutes les contributions passent par GitHub sous forme de Pull Request.
