**BH1750** — Mesurer la luminosité ambiante en lux pour suivre les périodes éclairées de la jardinière ou d’une station.

> **État de documentation :** informations issues du catalogue existant et du firmware Natulib OS V0.448. Le statut historique « Validé » est conservé ; les essais ci-dessous restent à consigner.

## 🌱 À quoi sert ce module ?

Mesurer la luminosité ambiante en lux pour suivre les périodes éclairées de la jardinière ou d’une station.

## 🔌 Branchement

VCC → 3,3 V ; GND → GND ; SDA et SCL → bus I²C partagé ; ADDR selon la variante.

**Avant toute connexion :** couper l'alimentation, identifier la variante exacte et vérifier la tension et les GPIO utilisés. Les GPIO4/5 des anciens exemples de câblage I²C ne doivent pas être considérés comme une recommandation universelle pour ESP32-C6.

### Câblage détaillé

> **Important :** brochage historique à confirmer pour la carte utilisée ; les valeurs du JSON ne garantissent pas la compatibilité de chaque GPIO.

| BH1750 | ESP32-C6 | Fonction |
|---|---|---|
| VCC | 3V3 | Alimentation |
| GND | GND | Masse |
| SDA | GPIO4 | Données I²C |
| SCL | GPIO5 | Horloge I²C |
| ADDR | GND ou 3V3 | Adresse I²C (`0x23` si GND, `0x5C` si 3V3) |

> 💡 Les GPIO indiqués ci-dessus sont un **exemple historique de câblage**, utilisable telle quelle pour un montage isolé. Dans une station qui combine plusieurs modules, le câblage réel peut différer : reportez-vous au plan de brochage de votre fiche **[Projet](../Projets.md)**.

## 🚀 Installation dans Natulib OS

1. Brancher le module hors tension, puis ouvrir l'interface web Natulib.
2. Dans Hardware, choisir BH1750, vérifier SDA/SCL et enregistrer. L’adresse 0x23 ou 0x5C est recherchée automatiquement lorsque la configuration ne force pas une adresse.
3. Vérifier le résultat dans **Accueil** ; consulter **Console** et **Maintenance** en cas d'erreur.

La configuration se fait depuis l'interface, **sans modifier de code Arduino**.

### Montage pas à pas

1. Soudez la barrette de broches si le module en est dépourvu.
2. Connectez le BH1750 à l'ESP32-C6 selon le tableau de câblage.
3. Reliez **ADDR à GND** (pour l'adresse `0x23`) ou **au 3,3 V** (pour `0x5C`).
4. Positionnez le capteur face à la principale source de lumière.
5. Fixez le module sans masquer sa cellule.
6. Démarrez Natulib OS et vérifiez les mesures.

## 📊 Mesures ou fonctions

`lux`, `online`

### Comprendre les paramètres

| Paramètre | Signification |
|---|---|
| `id` | Identifiant unique du module ; sert de préfixe aux mesures et dans les Synapses. |
| `name` | Nom visible dans l’interface. |
| `category` | Famille utilisée pour organiser les modules dans l’interface. |
| `type` | Type de driver sélectionné par Natulib OS. |
| `address` | Adresse I²C optionnelle : `null` laisse au driver le choix automatique lorsqu’il le permet. |
| `mux_addr` | Adresse d’un éventuel multiplexeur I²C ; `null` si inutilisé. |
| `mux_channel` | Canal d’un éventuel multiplexeur I²C ; `null` si inutilisé. |
| `pins` | Association entre les fonctions électriques et les GPIO ; **adapter au câblage réel**. |
| `pins.sda` | Ligne de données I²C. |
| `pins.scl` | Ligne d’horloge I²C. |
| `interval_ms` | Intervalle de mesure demandé, en millisecondes (1 000 ms = 1 seconde). Le comportement exact dépend du driver. |
| `mA` | Consommation indicative saisie dans le catalogue, **pas une mesure électrique certifiée**. |
| `factory` | Marqueur de configuration proposée par le catalogue d’usine. |
| `icon` | Icône du module dans l’interface. |
| `metrics` | Liste descriptive des mesures exposées dans Natulib OS (identifiants, intitulés et unités). |
| `actions` | Actions proposées dans l’interface et utilisables selon le driver. |

**Précision issue du driver ou du matériel :** Le driver `DeviceBH1750` utilise les paramètres optionnels d’adresse et de multiplexeur si configurés ; vérifier l’adresse et le câblage réels.

Pour débuter, utiliser l’onglet **Hardware** de Natulib OS : il génère la configuration. La modification manuelle du JSON est facultative.

## 🛠️ En cas de problème

- Vérifier les connexions, l'alimentation et les paramètres saisis dans **Hardware**.
- Consulter **Console** pour les erreurs et **Maintenance** pour les diagnostics.
- Une mesure en lux ne remplace pas un capteur PAR pour connaître précisément la lumière reçue par les plantes.

### Retours de dépannage

**Les valeurs restent proches de zéro**
→ La cellule est masquée par un cache, un boîtier ou un câble.

**Le capteur n'est pas détecté**
→ Le système détecte automatiquement les adresses `0x23` et `0x5C`. S'il n'est pas vu, vérifiez vos câbles SDA/SCL. Si vous utilisez plusieurs capteurs, assurez-vous d'avoir correctement forcé la clé `address` ou correctement configuré le canal du multiplexeur (`mux_channel`) dans le JSON.

### Informations complémentaires

**Précisions de la documentation historique :**

:**

- **Plug & Play :** Laissez `address` sur `null` si vous n'avez qu'un seul BH1750. Natulib OS détectera automatiquement s'il est sur `0x23` ou `0x5C`.
- **Multi-capteurs :** Si vous utilisez deux capteurs, forcez `address` à `35` (décimal pour 0x23) pour le premier et `92` (décimal pour 0x5C) pour le second afin d'éviter toute inversion.
- **Multiplexeur :** Pour brancher plus de 2 capteurs, utilisez un multiplexeur (ex: TCA9548A). Renseignez `mux_addr` (ex: `112` pour 0x70) et `mux_channel` (de `0` à `7`).


### Informations complémentaires

- Alimentez le module en **3,3 V**.
- Le BH1750 mesure la **lumière visible**, pas l'ensoleillement au sens météorologique.
- Une vitre, un cache ou un boîtier opaque peut modifier fortement la mesure.
- Pour une installation extérieure, prévoyez une **fenêtre transparente** ou une protection adaptée.
- Évitez d'exposer directement le module à la pluie.
