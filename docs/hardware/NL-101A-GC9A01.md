# 📺 NL-101A — Écran rond GC9A01

> 🟢 Validé · 🟢 Sans outil · 👤 Débutant · ⏱️ 5 min · 💰 ~5 € · 🔌 SPI

## 👀 En bref

Écran rond **GC9A01** connecté en **SPI** et intégré à **Natulib OS**.

Il affiche :

- 🌱 l'interface **Naturochi** ;
- 🌡️ les mesures des capteurs ;
- ⚠️ les alertes de la station.

**Alimentation :** 3,3 V · **Interface :** SPI · **Calibration :** aucune.

**💡 Rétroéclairage :** `GPIO2` pour un contrôle logiciel lorsque l'écran le permet · **[NL-401A](./NL-401A-PowerSwitch.md)** pour une coupure physique, utile en Deep Sleep.

## 🔌 Câblage

| GC9A01 | ESP32-C6 | Fonction |
|---|---|---|
| VCC | 3V3 | Alimentation |
| GND | GND | Masse |
| SCL | GPIO18 | SPI — SCK |
| SDA | GPIO19 | SPI — MOSI |
| RES | GPIO22 | Reset |
| DC | GPIO23 | Data / Command |
| CS | GPIO7 | Chip Select |
| BL | GPIO2 ou [NL-401A](./NL-401A-PowerSwitch.md) | Rétroéclairage |

> ⚠️ **Alimentation 3,3 V uniquement. Ne jamais connecter VCC au 5 V.**

> ⚠️ Certains GC9A01 conservent le rétroéclairage actif malgré une mise en veille logicielle.

> 💡 Les GPIO indiqués ci-dessus sont une **recommandation par défaut**, utilisable telle quelle pour un montage isolé. Dans une station qui combine plusieurs modules, le câblage réel peut différer : reportez-vous au plan de brochage de votre fiche **[Projet](../Projets.md)**.

## ⚙️ Configuration Natulib OS

**Type :** `screen` · **Pilote :** `gc9a01`

```json
{
  "id": "visage",
  "type": "screen",
  "driver": "gc9a01",
  "invert": true,
  "pins": {
    "sclk": 18,
    "mosi": 19,
    "dc": 23,
    "cs": 7,
    "rst": 22,
    "blk": 2
  },
  "active": true,
  "debug": false
}
```

| Paramètre | Fonction |
|---|---|
| `driver` | Pilote `gc9a01` |
| `invert` | Inversion des couleurs |
| `pins` | GPIO utilisés par l'écran |
| `active` | Active / désactive le module |
| `debug` | Journalisation SPI sur USB |

## 🛠️ Montage en 5 minutes

1. Préparez les **8 câbles Dupont**.
2. Connectez l'écran à l'ESP32-C6 selon le tableau de câblage.
3. Vérifiez toutes les connexions, en particulier **VCC → 3V3**.
4. Mettez sous tension et téléversez le firmware.
5. Vérifiez l'affichage de l'interface Naturochi.

---

## 🧩 Problèmes courants

**L'écran reste allumé en veille**
→ Le rétroéclairage de certains GC9A01 n'est pas coupé par la mise en veille logicielle. Utilisez le **[NL-401A](./NL-401A-PowerSwitch.md)** pour une coupure physique.

**Les couleurs sont inversées**
→ Passez `invert` à `false`.

**L'écran ne s'allume pas**
→ Vérifiez `VCC → 3V3`, `GND` et les GPIO du bus SPI.

---

## 💡 À retenir

- Alimentez l'écran en **3,3 V uniquement**.
- Le bus SPI mobilise six GPIO : anticipez-le avant d'ajouter d'autres modules.
- Le rétroéclairage peut être coupé logiciellement ou physiquement.
- Aucune calibration n'est nécessaire.
- L'inversion des couleurs dépend de la dalle reçue.
